# 디지몬 토큰 테이머 설계 문서

> AI 코딩 도구의 토큰 사용량으로 디지몬 어드벤처 파트너를 키우는 macOS 메뉴바 앱.
> 레퍼런스: [PokeTokenBar](https://github.com/chattymin/PokeTokenBar) (구조), DigiMonTokenBar (Choisiz, MIT; 디지몬 데이터 참고)
> 비공식 팬 프로젝트이며 Bandai/Toei와 관련이 없습니다.

## 1. 컨셉과 범위

- 포켓몬처럼 "많이 잡는" 게임이 아니라, 디지몬 세계관답게 **파트너(친구)를 키우는** 앱.
- 대상은 **디지몬 어드벤처 1기 주인공 파트너 8계열**뿐이다.
- 계열당 6단계: 유년기 I, 유년기 II, 성장기, 성숙기, 완전체, 궁극체.
- 분기 진화는 없다. 원작의 정식 진화 루트 한 줄만 쓴다.
- 총 48종이다.
- **제외 또는 보류:** 오메가몬, 암흑진화(스컬그레이몬 등), 아머체(페가수스몬, 네페르티몬).

|---|---|---|---|---|---|---|---|

## 2. 육성 시스템

### 2.1 디지타마 (알)
- **무늬가 계열을 정한다.** 계열마다 원작의 고유 디지타마가 있다. 랜덤 알은 쓰지 않는다.
- **첫 알은 무료다.** 사용자가 8종 중 하나를 고른다.
- **상점에는 8계열의 알이 항상 다 보인다 (2026-11-14 변경).** 이미 시작했거나 가방에 있는 계열은 "구매 완료"로 표시하고 다시 팔지 않는다. 첫 무료 알도 구매 완료로 보인다.
- **산 알은 가방에 들어간다.** 가방에서 "키우기"를 누르면 그 알이 파트너가 되고, 지금 파트너는 보관함으로 간다.
- **부화하면 유년기 I이 된다.** 유년기 II는 고르는 단계가 없다. 원작처럼 계열마다 정해져 있다.

### 2.2 진화 조건 (확정: 원작 순서 = B안)

| 진화 | 조건 |
|---|---|
| 유년기 I → 유년기 II → 성장기 | 게이지 100%이면 자동 진화 |
| 성장기 → 성숙기 | 게이지 100% + **디지바이스** |
| 성숙기 → 완전체 | 게이지 100% + **펜던트** + **문장이 빛남** |
| 완전체 → 궁극체 | 게이지 100% + **유대 레벨** (아이템 없음) |
| 궁극체 이후 | 게이지가 유대 레벨로 쌓인다 |

- **원작 근거:** 1기에서는 태그(펜던트)에 문장을 끼우고, 문장이 빛나면 완전체가 된다. 궁극체는 1기에서 워그레이몬과 메탈가루몬만 특별한 사건(빛의 화살과 워프진화)으로 도달했다. 8계열 모두에 통하는 원작 규칙이 없으므로 유대 레벨로 둔다. 빛의 화살 연출이나 워프진화 보상 같은 원작 장치는 넣지 않기로 했다.
- **퇴화는 없다.** 진화는 한 방향이다.
- **표시 형태 선택:** 설정에서 노트북에 등록된 형태 중 아무거나 골라 메뉴바에 띄울 수 있다. 이건 보이는 모습만 바꾸며 육성 상태는 그대로다. 기본값은 지금 키우는 파트너의 현재 형태다.

### 2.3 진화 가능 표시 "!"
- **진화 조건이 모두 충족됐을 때만** 메뉴바 캐릭터의 오른쪽 위 대각선 바깥에 주황색 "!"가 통통 튄다. 평소에는 보이지 않는다.
- 진화는 사용자가 "!"를 눌러 시작한다. 진화 장면이 재생된다.
- 무엇이 부족한지는 "!"가 아니라 **팝오버 카드의 게이지 아래 조건 줄**에서 항상 보여 준다.
  - 예: `완전체까지 ✓ 진화 게이지 100% ✓ 펜던트 · 용기의 문장 (57%)`

### 2.4 문장
- 계열마다 **고정 배정**된다. 부화하는 순간 어떤 문장인지 정해진다.
- **상점에서 팔지 않는다.** 업적을 달성하면 빛난다.
- 업적은 **8계열 모두 같은 난이도**로 둔다. 이름만 계열별로 다르게 붙인다.
  - 예: 용기의 시련 = "성숙기로 7일 함께하기". 수치는 미정이다.
- 진행도는 펜던트가 없어도 쌓인다. 문장은 펜던트를 사야 끼울 수 있다.
- 상태는 세 가지다: 꺼짐(회색 + 진행도), 끼움(펜던트 안의 회색 문장), 빛남(문장 색 + 반짝임).

### 2.5 상점 아이템

| 아이템 | 종류 | 역할 |
|---|---|---|
| 고기 | 소모품, 싸다 | 게이지와 유대를 올린다. 먹기 모션이 나온다. |
| 디지바이스 | 파트너마다 1회 구매 | 성장기 → 성숙기 진화의 열쇠 |
| 펜던트 | 파트너마다 1회 구매, 가장 비싸다 | 문장을 끼우는 장비이자 완전체 진화의 열쇠. 성숙기부터 상점에 나온다. |
| 디지타마 | 계열마다 1회 | 아직 시작하지 않은 계열의 알 |

- 이름은 "태그"가 아니라 **펜던트**로 통일한다. 원작을 모르는 사람도 바로 알아본다.
- **DigiMonTokenBar와의 차이:** 그쪽 펜던트는 경험치 소모품(+100M)이다. 우리 앱에서 그 역할은 고기가 맡는다.
- **가격과 게이지 기준값:** 아래 §2.6의 1차 값으로 구현했다. 확정이 아니며 조정할 수 있다.

### 2.6 1차 밸런스 값 (구현 2026-11-14, `Tamer/TamerBalance.swift`)

DigiMonTokenBar 기준을 근거로 잡았다. 하루 평균 약 253M 토큰, 일반 라인 졸업 750M, 알 5M, 디지바이스 100M이다. 토큰은 상류처럼 **성장 게이지와 상점 지갑에 동시에** 들어간다. 지갑은 사용 누적에서 지출 누적을 뺀 값이다. 그래서 아이템은 주는 성장보다 비싸게 둔다.

| 항목 | 값 | 비고 |
|---|---|---|
| 부화 | 5M | 부화하면 게이지는 0부터 |
| 게이지: 유년기 I / II | 15M / 30M | 차면 자동 진화, 진화하면 게이지는 0부터 |
| 게이지: 성장기 / 성숙기 / 완전체 | 100M / 200M / 300M | 100%에서 멈추고 이월하지 않음. "!" 대기 |
| 게이지: 궁극체 | 300M | 찰 때마다 유대 Lv +1, 게이지는 0부터 |
| 문장의 시련 | 성숙기 상태에서 **토큰을 쓴 날 7일** | 8계열 공통. 펜던트가 없어도 진행 |
| 유대 | 100점 = Lv 1, 궁극체 조건 Lv 5 | 고기 1개 = 유대 +50, 게이지 +5M |
| 가격: 고기 / 디지바이스 / 펜던트 / 디지타마 | 10M / 100M / 300M / 200M | 펜던트가 가장 비쌈 |

- **진화하면 게이지는 항상 0부터 다시 시작한다 (2026-11-14).** 넘친 토큰은 이월하지 않는다. 한 번 갱신에 많은 토큰이 들어와도 한 단계만 오른다. 지갑(상점 재화)은 그대로 쌓인다.
- 카드의 게이지 옆에 `64M / 100M`처럼 토큰 양을 보여 준다.
- **난이도 (PokeTokenBar처럼):** 설정 → 난이도의 슬라이더 두 개다. 로그 눈금이고 10%~200%, 기본은 100%이며 저장을 눌러야 적용된다.
  - 성장: 게이지 크기에 곱한다. 바꿔도 지금 게이지의 진행률(%)은 유지된다.
  - 상점 가격: 아이템 값에 곱한다.
  - 문장의 시련 일수와 유대 레벨에는 적용하지 않는다.
- 진화 아이템(디지바이스, 펜던트)은 진화할 때 없어지지 않고 파트너의 장비로 남는다.
- 설치 전에 쓴 토큰은 세지 않는다. 첫 갱신이 기준점이다. 장부 규칙은 DigiMonTokenBar의 프로바이더별 장부를 그대로 옮겼다.
- 새 디지타마를 사면 그 알이 지금 파트너가 되고, 기존 파트너는 보관함으로 간다. 보관 중인 파트너는 자라지 않는다.

## 3. UI

### 3.1 메뉴바
- 캐릭터 도트와 토큰 텍스트를 표시한다. 예: `200.7M` (한도 %는 설정에서 켤 때만, §3.2.2)
- 아이콘 폭은 캐릭터 폭에 "!" 배지 자리만 더한다 (§3.2.2). 처음에는 약 54pt 고정이었으나, 토큰 텍스트와 너무 떨어져서 줄였다.
- 22pt 이하인 형태는 정수 배율과 nearest-neighbor 보간으로 그린다. 큰 형태는 축소해서 그리며, 모션 랩에서 볼 때 뭉개짐은 문제없었다.
- 문장이 빛나는 순간에는 캐릭터 옆에서 문장 아이콘이 1~2초 반짝인다.

### 3.2 팝오버 파트너 카드 (목업: `assets/build/crest-mockup.html`)
위에서 아래 순서로 다음을 둔다.
1. 캐릭터 무대
2. 이름 · 계열 · 단계
3. 진화 게이지
4. 조건 줄
5. 장비/문장 줄
6. 힌트

장비/문장 줄은 단계에 따라 바뀐다.

| 단계 | 장비/문장 줄 |
|---|---|
| 성장기 | 디지바이스 (필요 → 보유) |
| 성숙기 | 펜던트 (필요 → 꺼진 문장을 끼움 + 시련 진행도 → 빛남) |
| 완전체 | 빛나는 펜던트 + 궁극체까지 유대 Lv |

연출은 세 가지다.
- **디지바이스 획득:** 아이콘이 튀어나온다.
- **펜던트 구매:** 꺼진 문장이 유리창으로 날아 들어간다.
- **문장 빛남:** 화면 중앙에 문장이 커지며 "용기의 문장이 빛났다!"가 뜬다.

### 3.2.0 카드 상단 (구현 2026-11-14, DigiTokenBar 홈 카드 방식)
- 처음 목업은 위쪽 무대가 카드 폭 전체(높이 150)를 차지했다. 너무 크다는 의견에 따라 바꿨다.
  - 왼쪽: 132pt 정사각 캐릭터 상자. 도트는 상자에 맞는 가장 큰 정수 배율(최대 3배)로 그린다.
  - 오른쪽: 계열·단계, 이름, 형·속성 칩과 그 오른쪽에 필살기(스킬) 칩, 진화 게이지(`64M / 100M`), "다음 진화까지 36M"
- 조건 줄 앞의 "성숙기까지" 같은 글자는 뺐다. 칩만 남는다 (2026-11-14).
- 조건 줄, 장비/문장 줄, 힌트 등 아래쪽은 그대로다.
- 형·속성·필살기는 DigiTokenBar 데이터(digimon.net 도감 기준)에서 48종 중 44종을 가져왔다.
  - 공식 설명문(발췌)은 저작권 때문에 넣지 않았다.
  - DigiTokenBar 데이터에 없는 뇨키몬, 유라몬, 피치몬, 유키미보타몬은 지어내지 않고 "프로필 정보 없음"으로 둔다.

### 3.2.1 팝오버 구성 (구현)
- 탭은 파트너, 상점, 가방, 노트북이다. 아래에 새로고침, 설정, 종료가 있다.
- **상점**은 고기, 디지바이스, 펜던트, 디지타마 8종을 항상 다 보여 준다. 디지바이스와 펜던트는 지금 파트너 기준으로 판단한다.
  - 이미 가진 것은 "구매 완료"로 표시한다.
  - 아직 살 수 없는 것은 이유를 적는다. 예: 펜던트는 "성숙기부터 살 수 있어요".
- **가방**에는 고기(먹이기), 지금 파트너의 장비(디지바이스, 펜던트와 문장 상태), 키우기 전인 디지타마가 들어 있다.
- 파트너 탭은 위에서부터 파트너 카드, **전체 서비스 · 상세 기록**, 사용 한도 순서다.
- DigiMonTokenBar의 DATA TRAFFIC 패널에서는 "전체 서비스 · 상세 기록"만 남겼다. 입출력 링, 주/월/프로바이더 레지스터, 활동 띠는 뺐다.
  - 남긴 것: 오늘 합계, 이번 주, 이번 달, 이번 달 일별 추이
  - 상세 기록은 접지 않고 항상 펼쳐 둔다.
  - **AI 툴 탭(Claude Code, Codex 등)은 상세 기록 안에 둔다 (2026-11-14).** 누른 탭의 오늘 구성(입력, 출력, 캐시, 모델)만 보여 준다.
- 사용 한도 패널은 상세 기록에서 고른 AI 툴의 한도를 보여 준다. 한도가 없는 툴이면 패널을 숨긴다.

### 3.2.2 메뉴바 (구현)
- 기본 표시는 `캐릭터 + 오늘 토큰`만이다. 예: `200.7M`
  - 처음에는 서비스 이름과 한도 %도 붙였으나 둘 다 뺐다 (2026-11-14).
- 설정 → 메뉴바에서 한도 %를 켜면 가장 높은 % 하나만 서비스 이름 없이 붙는다 (`200.7M · 82%`). 어느 서비스인지는 툴팁으로 보인다.
- 아이콘 폭은 캐릭터 폭에 "!" 자리(6pt)만 더한다. 처음 잡은 54pt 고정 폭은 텍스트와 너무 떨어져서 바꿨다 (2026-11-14).
- 팝오버는 목업처럼 밝은 테마로 고정했다. 시스템이 다크 모드여도 같다.

### 3.2.3 바탕화면 펫 (구현)
- DigiMonTokenBar의 플로팅 펫처럼 켜고 끈다 (설정, 팝오버 아래 눈 아이콘, 메뉴바 오른쪽 클릭 메뉴).
  - 메뉴바와 같은 형태가 대기 모션으로 통통 튀고, 진화할 수 있으면 "!"가 뜬다.
  - 스스로 걸어 다니지 않는다. 드래그로 옮기고(위치 기억), 클릭하면 팝오버가 열린다.
  - 오른쪽 클릭 메뉴: 팝오버 열기, 고기 주기, 숨기기
- 크기는 48~192pt다. 도트가 네모로 유지되도록 가장 가까운 정수 배율로 그린다.
- 진화, 부화, 문장 연출은 팝오버 전체를 덮어 재생한다. 카드 안에서는 큰 형태가 잘렸다.

### 3.2.4 이름과 탭 (구현 2026-11-14)
- **디지몬 이름은 한국어로 표시한다.** 공식 한국어 이름(digimon.net reference_ko, DigiTokenBar 데이터)을 쓴다.
  - 한국 공식 이름이 곧 어드벤처 현지화 이름이라 계열 이름(파피몬, 쉬라몬, 파닥몬, 가트몬)과 맞는다. 예: 깜몬, 가루몬, 원뿔몬, 니드몬, 야옹몬, 어니몬, 둥실몬, 뽀글몬, 시드몬, 페닉스몬, 바이킹몬
  - 공식 한국어 항목이 없는 4종은 음역했다: 뇨키몬, 유라몬, 피치몬, 유키미보타몬 (`koUnverified`). 영어 설정에서는 영문명을 쓴다.
- 팝오버 맨 위의 "디지몬 토큰 테이머" 제목은 없애고, 탭 4개를 왼쪽으로 붙였다.
- 상점의 토큰 값은 단위 글자 없이 M으로만 보인다. 예: `1,546M`, `10M`, `200M`
- 탭 내용은 스크롤바 없이 스크롤한다. 상류가 오른쪽에 남겨 둔 12pt 스크롤바 자리 때문에 카드가 왼쪽 14pt, 오른쪽 26pt로 치우쳐 보였다 (노트북 정렬 문제의 원인).
- 힌트의 "상점" 같은 문장 속 동작은 파란 밑줄 링크가 아니라 주황 알약 버튼(`상점 ›`)으로 오른쪽에 둔다.

### 3.3 노트북 (도감)
- 계열마다 한 줄씩, 맨 앞에 문장 엠블럼이 있다. 문장을 빛내 본 계열은 엠블럼에 색이 들어간다.
- 6단계 칸이 있고, 아직 못 본 형태는 실루엣으로 보인다.
- 등록된 형태를 누르면 **아날라이저**(코시로의 디지몬 아날라이저)가 열린다. DigiTokenBar의 도감 상세처럼 구성했다.
  - 큰 도트
  - 한국어·영문 이름, 계열·단계
  - 디지몬 정보: 세대, 형, 속성, 필살기, 공식 도감 링크
  - 진화 루트: 6단계와 각 단계의 조건, 등록 안 된 형태는 실루엣
  - 그 계열의 문장 상태
  - "메뉴바에 띄우기" 버튼
- 공식 프로필 설명문은 저작권 때문에 옮기지 않고 공식 도감 링크로 대신한다.
- **메뉴바 표시 형태 (2026-11-14):** 설정의 선택지는 "지금 파트너 따라가기"와 "노트북에서 선택…" 두 개뿐이다.
  - "노트북에서 선택…"을 누르면 노트북이 선택 모드로 열리고, 등록된 형태를 누르면 바로 적용된다. 설정에서 왔으면 설정으로 돌아간다.
  - 노트북 상단의 "메뉴바 형태 고르기"로도 같은 선택 모드에 들어갈 수 있다.
  - 아날라이저의 "메뉴바에 띄우기"도 그대로 쓸 수 있다.
- 이름은 "수첩"에서 **노트북**으로 바꿨다 (2026-11-14).

## 4. 모션 (목업: `assets/build/motion-lab.html`)

### 4.0 앱에서 쓰는 방식 (구현 2026-11-14)
모션 랩의 프레임을 그대로 옮겼다 (`Tamer/PartnerMotion.swift`). 카드, 바탕화면 펫, 메뉴바가 같은 규칙을 따른다.

| 언제 | 모션 | 비고 |
|---|---|---|
| 평소 | 걷기 | 기본 동작이다. 토큰을 많이 쓰는 중이면 조금 빠르게 걷는다 |
| 캐릭터를 클릭 (카드 상자, 바탕화면 펫) | 쓰다듬기: 하트가 올라감 | 보기만 하는 효과다 (보상 없음) |
| 너무 많이 클릭 (6초 안에 5번) | 짜증: 분노 표시와 함께 흔들다 돌아섬 | 잠시 쉬면 다시 하트가 나온다 |
| 진화 조건이 모두 갖춰짐 | 점프하면서 "!" | 무엇보다 우선한다. "!"는 캐릭터 오른쪽 위에 붙어 같이 뛴다 |
| 토큰 갱신이 안 됨 | 잠: 어두워지고 Z | 마지막 정상 갱신이 갱신 주기의 2배보다 오래됐거나, 첫 갱신부터 실패한 경우 |
| 고기 주기 | 먹기: 고기를 세 번 베어 먹음 | |
| 진화·부화 연출이 끝난 뒤, 아이템 구매 | 기쁨: 음표와 함께 깡충 | |

- 위 규칙은 2026-11-14 사용자가 정했다. 그 전에 쓰던 "한도 경고면 삐짐", "오늘 사용이 없으면 잠"은 이 규칙으로 바뀌었다.
- 메뉴바는 22pt라서 걷기 대신 좌우로 돌며 통통 튀고(많이 쓰는 중이면 빠르게), 잠(어둡게 + Z)과 "!"만 보인다. "!"가 있으면 "!"가 우선이다.
- 바탕화면 펫은 클릭하면 쓰다듬고, 더블클릭하면 팝오버가 열린다.
- **방향:** 모든 스프라이트는 **오른쪽을 본다.** 왼쪽으로 걸을 때는 좌우 반전한다.
- **렌더링:** 정수 도트 단위로 움직이고, 프레임은 steps 방식이다. 보간 없는 픽셀 렌더링을 쓴다.
- **모션 목록:** 대기, 걷기, 기쁨, 먹기(고기), 쓰다듬기(하트), 잠(Z), 삐짐, 진화, 진화 가능(!), 부화. 퇴화는 표시 형태를 바꿀 때 쓰는 연출 확인용이다. **공격은 없다.**
- **진화 장면:** 실루엣이 점점 빠르게 깜빡이며 다음 형태와 교차하다가, 흰 섬광 뒤 새 형태가 나타난다.
- **부화:** 알이 흔들리다 금이 가고, 흰 섬광 뒤 유년기 I이 나온다.
- **프레임 포맷:** `{d, dx, dy, flip, mode:'black'|'white'|'dim', who:'cur'|'next'|'egg'…, ov:[아이콘 오버레이], flash}`. 오버레이 아이콘(고기, 하트, Z, 분노, 음표, 반짝임, 금, !)은 오리지널 도트다.

  - `~/Library/Application Support`에 캐시한다.
  - 비공식, 비상업 고지를 넣는다.
  - THIRD_PARTY_NOTICES를 둔다.
- **앱이 Wikimon이나 나무위키를 직접 링크해 쓰지 않는다.**
  - Wikimon robots.txt의 Crawl-delay는 60이다.
  - 수집 스크립트는 UA `DigiTokenBar-research/0.1`을 쓰고 요청 사이에 3~5초를 쉰다.

## 7. 결정 기록 (왜 이렇게 했나)
- **8계열만 다루기:** 디지몬은 포켓몬과 달리 "파트너" 개념이다. 사람들이 원하는 건 주인공 파트너다.
- **분기 진화 없음:** 원작에서도 유년기 II를 고르는 단계가 없다.
- **문장은 상점에서 팔지 않음:** 원작에서 문장은 성장으로 빛나는 것이다. 팔면 업적의 의미가 사라지고, 다른 계열 문장 7종은 쓸모없는 진열이 된다.
- **완전체 조건 = 펜던트 + 문장 (B안):** 원작 순서를 따랐다. 처음 안(A안)은 펜던트를 궁극체 조건으로 두었지만, 원작과 맞지 않아 바꿨다.
- **"!"는 진화 가능할 때만:** 평소에는 화면을 깔끔하게 두고, 조건은 카드에서 확인한다.
- **이름은 태그 대신 펜던트:** 원작을 모르는 사람도 바로 알아본다.
- **아이템과 문장 디자인은 원작에 맞춤:** 문장, 펜던트, 디지바이스, 디지타마 모두 공식 디자인을 기준으로 다시 그렸다.
- **DigiMonTokenBar 코드를 베이스로 하고, 디자인은 직접 만든 것으로 (2026-11-14):** 사용량 수집과 한도는 검증된 상류 코드를 쓴다. 게임과 화면은 이 문서와 목업대로 새로 짰다.
- **DATA TRAFFIC은 "전체 서비스 · 상세 기록"만 남김 (2026-11-14):** 파트너 카드가 주인공이고, 사용량은 서비스 전체 기록 하나로 충분하다.
- **앱 아이콘은 D1+ 디지바이스형 (2026-11-14):** 오리지널 V-Pet 기기(A안)부터 디지바이스에 가까운 쪽(D1, D1+)까지 비교한 뒤 골랐다.
  - 기존 디지바이스 도트(`tools/digivice.py`)의 구조와 색을 따르고, 액정에 앱의 디지타마를 넣었다.
  - 큰 크기는 40×38 원본을 정수 배율로 키우고, 16px는 손으로 다시 찍었다.
  - 아이콘은 앱 안에 있어야 하므로 저작권 에셋을 커밋하지 않는다는 규칙의 유일한 예외로 두고, NOTICE에 팬아트임을 밝혔다.
- **GitHub에서 받아 바로 쓰기 (2026-11-14):** DigiTokenBar처럼 Release zip만 받아도 이미지가 나와야 한다. 앱에는 이미지를 넣지 않고, 별도 공개 저장소에서 첫 실행 때 내려받는다 (§5.2 원칙 유지).
